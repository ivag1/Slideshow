How the app works

1. Array: All images are stored inside the images array. An array is a list of values. The first item is at position 0.

2. Current image: The variable currentImage remembers which image is currently shown.

3. Next button: nextImage() increases currentImage by 1. If it reaches the end, it goes back to the first image.

4. Previous button: previousImage() decreases currentImage by 1. If it goes before the first image, it jumps to the last image.

5. Automatic slideshow: startSlideshow() uses setInterval() to call nextImage() every 2 seconds.

6. Loop: showSmallImages() uses a for loop to create all thumbnail images under the main image.
